Developed a novel non-contact biomedical system that monitors Heart Rate Variability (HRV) through real-time analysis of pupillary fluctuations captured via a standard webcam. The autonomic nervous system modulates pupil diameter in sync with cardiac cycles, enabling HRV estimation without physical sensors — bridging computer vision, biomedical signal processing, and machine learning.

  • Implemented real-time pupil detection and segmentation using OpenCV and Dlib facial landmark detection with sub-pixel precision.

  • Computed standard HRV metrics — SDNN, RMSSD, pNN50, LF/HF ratio — from pupillary fluctuation data, validated against contact-based reference sensors.
  • Developed a Flask web application with live video feed, real-time HRV dashboard, and autonomic stress-state classification using trained ML models.
  • Applied Butterworth bandpass filtering, noise reduction, and artifact rejection algorithms to ensure signal fidelity under varied lighting conditions.
  • Evaluated system accuracy against standard PPG reference, demonstrating reliable non-invasive autonomic biomarker estimation.
  • Technologies: Python, OpenCV, Dlib, NumPy, SciPy, Scikit-Learn, Flask, Matplotlib, Signal Processing, HRV Analysis
